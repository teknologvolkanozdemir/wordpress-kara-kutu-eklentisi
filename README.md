# wordpress-kara-kutu-eklentisi
bu eklenti, wordpress üzerinde yapılan tüm işlemleri kayıt eder, kayıtların silinmesi mümkün değildir. yapılan tüm işlemleri, kara kutu sayfasından görüntüleyebilirsiniz. kara kutu sayfası, wordpressin yönetim panelindedir, sadece yöneticiler görebilir.

## Kurulum

`kara-kutu` klasörünü `wp-content/plugins/` altına kopyalayıp etkinleştirin. Kayıtlar **Kara Kutu** menüsünde sayfalı listelenir. Eklentide silme arayüzü yoktur; veritabanı tetikleyicileri (yetki varsa) UPDATE/DELETE işlemlerini de engeller ve eklenti kaldırıldığında tablo silinmez.
